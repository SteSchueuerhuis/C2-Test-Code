This repository contains the code used to reproduce the results from the paper 

Schüürhuis, S., Konietschke, F., & Brunner, E. (2025). A new approach to the nonparametric Behrens–Fisher problem with compatible confidence intervals. Biometrical Journal, 67(6), e70096.

Link: https://onlinelibrary.wiley.com/doi/10.1002/bimj.70096

The attached Quarto file (README.qmd) and its compiled version (README.html) contain detailed documentation of the code.
